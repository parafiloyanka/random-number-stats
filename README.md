# C++ Statistical Functions Lab 📊

Консольна програма мовою C++ для генерації масивів випадкових чисел та проведення базового статистичного аналізу. Проєкт розроблено в рамках лабораторної роботи для дослідження процесу створення та використання функцій користувача.

## ⚙️ Основний функціонал
- **Генерація даних:** Створення масивів псевдовипадкових чисел у діапазоні від 0 до 1 (`gen()`).
- **Статистичний аналіз:** 
  - Розрахунок математичного сподівання / середнього значення ($M_x$).
  - Обчислення стандартного (середньоквадратичного) відхилення ($q$).
- **Сортування та виведення:** Сортування згенерованого масиву за зростанням та форматоване виведення результатів у консоль (з точністю до 6 знаків після коми).
- **Аналіз похибок:** Порівняння обчислених статистичних показників із заданими (очікуваними) значеннями та виведення абсолютної похибки.
